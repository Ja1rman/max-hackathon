# Соответствие проекта критериям

Проект «За столом» сопоставлен с предоставленными критериями оценки. [Руководство по интерфейсу](INTERFACE_GUIDE.md) и [руководство организатора](ORGANIZER_GUIDE.md) показывают основной сценарий на снимках опубликованной [демоверсии](https://mail.lonelycraft.ru/banquet/).

| Критерий | Реализация в проекте |
| --- | --- |
| Работоспособность и полнота функций · 30% | Сквозной сценарий объединяет вход, создание банкета, приглашение гостей, выбор меню или пакета, бюджет, рассадку, личный выбор гостя, утверждение заказа и выгрузку для кухни. Четыре роли представлены в демоверсии. |
| Корректность интеграции и обмена данными · 20% | Mini App обменивается данными с Node API; SQLite хранит сессии, каталог, бронь и заказы. [OpenAPI 3.1](../openapi.yaml) и [DATA-API.yaml](../DATA-API.yaml) описывают методы и форматы. Интеграция MAX включает подписанный вход, подтверждение телефона, приглашения через `startapp`, webhook и сообщения бота. |
| Стабильность и обработка ошибок · 10% | Сервер проверяет права, бюджеты, версии заказов и пересечения бронирования. Ошибки API имеют определённые HTTP-статусы; интерфейс показывает сообщения на русском языке внизу экрана. События webhook дедуплицируются, данные сохраняются в SQLite. |
| Техническая реализация и архитектура · 20% | React Mini App, Node API, модуль SQLite и MAX-интеграция разделены. Сервер рассчитывает суммы и проверяет доступ, а меню банкета сохраняется отдельным снимком. [Docker Compose](../compose.yaml) запускает локальные компоненты одной командой. |
| Безопасность, зависимости и данные · 10% | `package-lock.json` фиксирует версии; `.env` исключён из Git и Docker-контекста. Реализованы проверка подписей MAX, разграничение ролей, срок сессии, ограничение частоты входа, изоляция демо, одноразовые ссылки выгрузки и CSP. Контейнер работает без root с файловой системой только для чтения. |
| Техническая документация и комплектность · 10% | [README](../README.md) описывает запуск, окружение, порты, архитектуру и работу с данными. В репозитории есть Dockerfile, Compose, `.dockerignore`, `.env.example`, lockfile, [OpenAPI](../openapi.yaml), [DATA-API](../DATA-API.yaml), [тестовые данные](../fixtures/api-checks.json), [инструкция API](TESTING.md), [руководство по интерфейсу](INTERFACE_GUIDE.md) и [руководство организатора](ORGANIZER_GUIDE.md). |
| Платформенный бонус MAX · +0,15 балла | [Сценарий MAX](MAX.md#пользовательская-ценность-возможностей-max--критерий-015-балла) связывает возможности платформы с задачами пользователя: подтверждённый номер находит приглашения, `startapp` и `shareMaxContent` упрощают приглашение, уведомления ведут в банкет, а нативная выгрузка помогает ресторану. |

## Порядок демонстрации

1. В [демоверсии](https://mail.lonelycraft.ru/banquet/) показать четыре роли: организатора, гостя, администратора ресторана и администратора сервиса. Пройти путь от создания банкета до заказа для кухни.
2. В MAX показать вход в Mini App, подтверждение номера, приглашение второго пользователя, выбор гостя и сообщение бота. [Сценарий MAX](MAX.md) содержит действия для двух аккаунтов.
3. Открыть [Swagger UI](https://mail.lonelycraft.ru/banquet/swagger/) и [OpenAPI](../openapi.yaml) для обзора API и форматов данных.
