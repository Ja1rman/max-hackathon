# Проверка проекта по критериям

Проверено 29 сентября 2026 года по текущему коду, опубликованной демоверсии и публичному API. Это сопоставление с предоставленной таблицей критериев, **не прогноз баллов жюри**. Полный повторяемый прогон: `npm run check` — 63/63 теста и production-сборка; `npm run api:check` — 36/36 обязательных проверок на `https://mail.lonelycraft.ru/banquet/api/v1`. [Пошаговый интерфейс](INTERFACE_GUIDE.md) и [руководство организатора](ORGANIZER_GUIDE.md) иллюстрируют настоящие снимки опубликованной демоверсии. Демо изолировано от реальных пользователей MAX.

Тесты покрывают роли, брони, пакеты и редактирование. | Пройти сценарий на двух **реальных** аккаунтах MAX перед показом. ## Короткий порядок показа

1. На [демоверсии](https://mail.lonelycraft.ru/banquet/) переключить четыре роли в одном изолированном пространстве: организатор, гость, администратор ресторана, администратор сервиса. Показать два банкета, меню, место, кухню и ограничения доступа.
2. Повторить `npm run api:check` и показать итог `36/36` вместе с Swagger/OpenAPI. Прогон создаёт своё демо-пространство и не меняет реальные заказы.
3. В настоящем MAX пройти сценарий из [MAX.md](MAX.md): вход, подтверждение номера, приглашение, выбор гостя и уведомление. Не выдавать браузерные снимки за доказательство нативной интеграции.
